# Permission

All materials were obtained from Natural Language Processing module (Summer Term 2026) and are used with the written permission of the module convenor, Dr. Paul Nulty. The repository is private and is accessible by the author and Birkbeck staff (supervisor, markers). Not for redistribution. 

# Contents
- lecture slides (PDF, exported from the original PPTX for parser compatibility)
- lab sheets (no solutions)
- module handbook 

# Deliberate exclusions
For design, evaluation, pedagogical as well as for privacy  purposes:
- no student-generated content (forums, submissions)
- no lab solutions
- no revision decks; reserved as instructor-authored evaluation material
